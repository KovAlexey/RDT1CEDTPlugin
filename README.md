
# Плагин для интеграции с инструментами отладки в EDT

**Установка:**
1) Добавить репозиторий в эклипс
>https://kovalexey.github.io/RDT1CEDTPlugin/master
2) Установить

**Реализовано:**
1) Отладка переменных и выражений (пункт меню "Отладить")

Поддерживает до двух параметров. Если параметр один - передает его в метод отладки (по умолчанию `ИрОбщий.От`). Шаблон выражения для отладки можно настроить в параметрах плагина (вкладка `RDT1C -> Отладить`).

Если два - проверяет являются ли они схемой компоновки и настройками - затем отправляет их в метод отладки (например, `ИрОбщий.От(Схема, Настройки)`).
Три и более - не поддерживается.

Поддерживаются выражения через точку.

![изображение](https://github.com/KovAlexey/RDT1CEDTPlugin/assets/16429518/0915bb9f-1ca6-40c1-ae67-8c259b5f6cbf)

2) Динамический код (пункт меню "Динамический код")
![изображение](https://github.com/KovAlexey/RDT1CEDTPlugin/assets/16429518/6bbc83e5-7b8f-42fa-ba46-9a18ecb7956e)

- Настройка выражения/шаблона метода выполнения (по умолчанию `ИрОбщий.Ду`) в параметрах плагина (вкладка `RDT1C -> Динамический код`).
- Реализована передача контекста локальных переменных в открываемый редактор (автодополнение).
- Реализована упаковка контекста в параметры метода выполнения (через Структуру).
- Улучшена обработка исключений при выполнении отладочных команд.
